# Build the Windows Installer with Inno Setup

Run this after completing `BUILD_PYINSTALLER.md`.

## 1. Install Inno Setup

Install Inno Setup 6 from the official download page:

<https://jrsoftware.org/isdl.php>

You can install it interactively or with winget:

```powershell
winget install --id JRSoftware.InnoSetup -e -s winget -i
```

## 2. Confirm the PyInstaller output exists

This folder must exist before compiling the installer:

```text
dist/Video2Text/
```

It must contain:

```text
Video2Text.exe
```

## 3. Optional: include Microsoft Visual C++ Redistributable

Download the x64 redistributable from Microsoft and place it here:

```text
vendor/redist/vc_redist.x64.exe
```

The installer script runs it silently when present. It is skipped when missing.

## 4. Compile the installer

From the repository root:

```powershell
iscc .\installer\Video2Text.iss
```

If `iscc` is not in `PATH`, use the full path, for example:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" .\installer\Video2Text.iss
```

## 5. Output

The installer is created here:

```text
installer_output/Video2TextSetup-1.0.0.exe
```

## 6. Test on a clean Windows machine

Install the generated setup file and verify:

- The wizard installs without asking for Python.
- The Start Menu shortcut launches the app.
- The optional desktop shortcut works if selected.
- A sample media file can be transcribed.
- Video input works when FFmpeg is bundled or installed in `PATH`.

## Installer behavior

- Installs per user under `%LOCALAPPDATA%\Programs\Video2Text`.
- Adds Start Menu and optional Desktop shortcuts.
- Launches the app at the end of installation.
- Includes every file generated by the PyInstaller one-folder build.
